01 BACKGROUND

직접 만들고 반복하는 점자 학습

에듀블은 점자를 학습하는 사용자가 직접 점자를 만들고, 입력 결과를 확인하며 반복적으로 학습할 수 있도록 설계된 IoT 기반 교육 서비스입니다. 모바일·웹 기반 학습 앱과 물리적인 점자 학습 기기를 함께 활용해 점자 입력 연습과 단계별 학습을 지원합니다. 기기는 물리적인 버튼과 LED로 입력 및 안내 기능을 제공하고, 앱은 학습 단계와 문제를 확인하며 학습 과정을 진행하도록 지원합니다.

02 PROBLEM

학습 목적에 맞는 정보 전달

점자 학습이라는 서비스 목적에 맞춰 학습자가 필요한 정보를 명확하게 확인하고, 프로젝트에서 정의한 학습 흐름을 따라갈 수 있도록 화면을 구성하는 것이 담당 작업의 과제였습니다.

03 MY ROLE

앱 화면 구현과 기기 동작 테스트

팀 프로젝트에서 학습 앱의 프론트엔드 UI와 일부 화면 구현을 담당했습니다. 서비스의 특성을 이해하고 사용자가 학습에 필요한 정보를 확인하도록 앱 화면을 구성하는 작업에 참여했습니다. 사물인터넷 전공을 바탕으로 점자 학습기의 물리적 버튼과 LED 동작을 확인하는 테스트도 수행했습니다. 전체 서비스의 설계와 개발은 팀과 함께 진행했으며, 제 기여 범위는 앱 화면 구현과 하드웨어 동작 검증입니다.

04 APPROACH

화면에서 실제 조작까지

  1. 01

    점자 학습 앱 UI 및 화면 구현

    점자 학습 서비스에 필요한 앱 화면 일부를 구현했습니다. 학습 정보가 명확하게 전달되도록 화면을 구성하고, 텍스트·버튼·주요 UI 요소를 배치했습니다. 프로젝트에서 정의한 학습 흐름에 맞춰 사용자 인터페이스를 구현했습니다.

  2. 02

    사용자 중심의 학습 화면 구성

    점자 학습이라는 서비스 목적을 고려해 화면을 구성했습니다. 학습자가 필요한 정보를 쉽게 확인할 수 있도록 UI 요소를 정리하고, 학습 화면의 구성 요소와 시각적 정보 전달 방식을 검토했습니다.

  3. 03

    IoT 하드웨어 버튼 및 LED 동작 테스트

    점자 학습기의 물리적 버튼 동작 상태와 버튼 조작에 따른 기기 반응을 점검했습니다. LED 점등 및 표시 상태를 확인하고, 하드웨어가 의도한 방식으로 동작하는지 기본 기능을 테스트했습니다.

05 RESULT

팀 프로젝트 기여와 수상

학습 앱의 일부 UI와 화면을 구현하고, 점자 학습기의 물리적 버튼과 LED에 대한 기본 동작 테스트를 수행했습니다. 앱 화면 구현과 하드웨어 동작 검증을 중심으로 팀 프로젝트에 기여했습니다.

수상 · 충남 학생 창업경진대회 · 대상

06 LEARNINGS

앱과 기기가 함께 만드는 경험

사용자의 학습 목적과 서비스 특성을 고려해 UI를 구현하는 경험을 쌓았습니다. 실제 사용자가 조작하는 하드웨어의 버튼과 LED 동작을 함께 확인하면서 IoT 서비스가 여러 구성 요소의 상호작용으로 이루어진다는 점을 이해했습니다. 프론트엔드 개발에서도 화면 구현뿐 아니라 실제 사용 환경과 사용자 경험을 고려하는 것이 중요하다는 점을 배웠습니다.
