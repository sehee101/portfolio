Posture Correction System

센서의 데이터를,
이해할 수 있는 피드백으로.

카메라와 FSR 센서가 감지한 자세 데이터를 Flutter 앱의 점수와 피드백으로 전달하는 실시간 자세 교정 시스템입니다.

ROLE
Flutter 앱 UI
TYPE
졸업 팀 프로젝트
STACK
Flutter / Firebase / Real-time Data
BackgroundProblemMy RoleApproachResultLearnings
01 BACKGROUND

센서와 앱으로 연결한 자세 교정

카메라와 FSR 센서, Raspberry Pi, Firebase, Flutter 앱을 연결한 자세 교정 시스템입니다. 감지·분석 결과를 사용자가 확인하는 앱 화면으로 전달합니다.

02 PROBLEM

분석 데이터를 읽기 쉬운 피드백으로

센서와 카메라의 분석 데이터를 그대로 보여주는 대신 사용자가 확인할 수 있는 점수와 피드백으로 변환하는 것이 화면 구현의 과제였습니다.

03 MY ROLE

Flutter 앱 UI와 실시간 연동

Flutter 점수 UI, 실시간 데이터 연동, 일간·주간·월간 피드백 화면을 구현했습니다. 주요 담당 영역은 사용자가 데이터와 피드백을 확인하는 앱 인터페이스입니다.

04 APPROACH

데이터를 화면 언어로 전환

  1. 01

    데이터에서 화면까지 연결

    카메라와 FSR 센서의 데이터를 Raspberry Pi와 Firebase를 거쳐 Flutter 앱에서 확인하는 시스템 흐름에 앱 UI를 연결했습니다.

  2. 02

    기간별 피드백 표현

    일일 점수와 피드백, 주간·월간 변화를 앱 화면으로 구성했습니다.

  3. 03

    작동 과정의 증거 남기기

    발표자료의 실제 시연, 센서·카메라 구성, 자세 감지 화면과 앱 화면을 함께 정리했습니다.

05 RESULT

점수와 기간별 피드백 구현

Flutter 앱의 점수와 피드백 화면을 구현했습니다. 원본 발표자료에 하드웨어 구성과 실제 시연 장면이 포함되어 있습니다.

06 LEARNINGS

실시간 데이터를 이해하는 화면

실시간 데이터를 점수와 피드백이라는 화면 언어로 표현하는 경험을 쌓았습니다.
